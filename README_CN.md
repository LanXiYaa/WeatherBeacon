# WeatherBeacon

**Windows 桌面天气小组件 · 首次正式发布 · 1.0.0.0**

[English](README.md) | 简体中文

WeatherBeacon 将当前天气、逐小时预报和未来五日天气放在一张毛玻璃风格卡片中。拖动到喜欢的位置，让天气随时可查。

> **由 AI 制作：本项目的代码、界面和文档主要由 AI 生成与辅助修改，由项目维护者提出需求、进行测试并决定发布。**

## 功能亮点

- **天气一览**：当前温度、天气描述、逐小时预报、未来五日天气及高低温；今日高亮，显示“中雨”“晴转多云”等天气名称。
- **毛玻璃风格**：半透明卡片、柔和渐变、天气图标和动态背景，支持关闭动画、调整不透明度与圆角。
- **灵活摆放**：拖动小组件、锁定位置或重置位置，保存后下次启动恢复。
- **城市选择**：手动搜索，或通过 IP 查询大致位置并确认城市。
- **温度单位**：支持摄氏度 ℃ 与华氏度 ℉。
- **自动更新**：默认每 15 分钟刷新，可选 5、10、15、30、60 分钟。请求失败后保留本次运行中的有效数据并自动重试。
- **托盘操作**：单击显示／隐藏，双击打开设置，右键切换显示状态、打开设置或退出。
- **开机自启**：当前用户登录时启动，无需管理员权限；自启时不主动弹出设置。
- **单实例**：重复启动会唤起已有实例。
- **预警通知**：小米真实预警、Windows Toast、蓝／黄／橙／红等级阈值，跨重启去重。默认关闭，可在“通知”页开启。
- **开发者预览**：在“关于”页确认开启后，可切换天气与昼夜、恢复真实天气并发送带调试标记的系统通知。

## 下载与运行

本次发布提供 **Windows x64 自包含版本**，面向 Windows 10 1903 或更新版本 / Windows 11 的 64 位设备，无需另行安装 .NET 运行时。

1. 下载并解压完整发布包。
2. 运行 `WeatherBeacon.exe`。
3. 双击托盘图标打开设置，在“天气”页搜索城市，或使用 IP 自动定位，确认后应用。
4. 按需调整外观、刷新间隔和温度单位，点击“保存设置”。

请保留 EXE 旁的依赖文件，不要只移动 EXE。更新前先通过托盘退出旧版，再运行新版本。

## 使用提示

- 小组件采用**普通非置顶窗口**，其他应用可以覆盖它。按 Win+D 时可能一起隐藏，可通过托盘重新显示；本版不保证桌面层常驻。
- 小组件的毛玻璃效果来自应用内部的半透明叠层和背景模糊，不是对桌面内容进行实时模糊。设置窗口可选择系统材质，不支持时降级显示。
- 如在任务管理器中禁用了自启，请在那里重新启用；软件不会擅自覆盖系统禁用状态。
- 移动程序目录后，手动从新路径启动一次，软件会在自启已开启且未被系统禁用时更新启动项。
- IP 定位可能受到 VPN、代理及运营商出口影响，使用前请确认城市。

## 数据与隐私

天气与城市搜索使用小米天气接口。点击 IP 定位时，会向 `ipwho.is` 查询大致位置，再交给小米接口匹配城市；网络服务会接收到请求所需的信息。

配置保存在 `%LOCALAPPDATA%\WeatherBeacon\settings.json`。现有桌面诊断文件保存在程序目录的 `logs` 中，包含窗口状态、位置、显示器布局和动画状态等排错信息，默认仅保存在本地。反馈问题前可自行查看内容。

通知去重状态保存在同一配置目录的 alert-delivery.json，按城市和预警类型记录内容指纹；调试通知不写入该文件。通知采用固定 AppUserModelID WeatherBeacon.Desktop，并创建当前用户开始菜单中的 WeatherBeacon 快捷方式，统一名称、图标与 COM 激活器，无需管理员权限。移动便携版后从新位置启动，会更新快捷方式和激活路径；后续移动保持同一通知身份。旧版本遗留的路径身份可能仍显示在系统中。

预警更新／升级替换同一条通知，确认解除后清除；降级至阈值以下时清除旧的高等级通知。正文显示两行摘要，时间使用 Windows 自带显示，支持“知道了”关闭和点击正文打开设置。调试标题使用 [调试] 前缀。通知留存遵守 Windows 自身的保留策略，应用不再为调试通知设置五分钟过期。

开发者天气覆盖只在内存中生效；恢复按钮、关闭开发者模式或重启均恢复真实天气。调试 Toast 遵守通知总开关、忽略阈值，明确标注“调试”。

本版没有系统硬件信息收集功能，也没有日志自动上传功能。第四步说明见 [原交付记录](docs/STAGE4_COMMIT.md)，最新通知修复与验收范围见 [通知修复说明](docs/TOAST_FIX_COMMIT.md)。

## 当前限制

- 暂无经过验证的分钟级降水数据，**不提供下雨／雨停分钟倒计时**，也不使用小时预报推算分钟。
- 未包含首次使用向导或系统硬件信息日志功能。
- 预警随天气刷新读取，不是实时推送服务。只支持已验证的小米 alerts 结构；字段缺失、未知等级或解析不支持时明确提示，不伪造预警。
- Windows 允许通知不代表必定弹出横幅；勿扰／专注助手可能只保留通知中心消息。通知页显示可查询到的禁用状态。
- 天气服务可用性与覆盖范围取决于第三方接口；断网期间不会产生新预报，退出程序后不保留天气快照。
- 不同 Windows 版本的自启状态、材质和多屏 DPI 行为可能存在差异；实际登录自启、断网恢复及所有硬件组合尚未完成全面验证。

## 从源码构建

技术栈：**C#、WPF、.NET 10**。安装 .NET 10 SDK 后，在本仓库目录运行：

```powershell
dotnet publish src/WeatherBeacon.App/WeatherBeacon.App.csproj -c Release -r win-x64 --self-contained true -o output/win-x64
```

发布结果位于 `output/win-x64`，运行其中的 `WeatherBeacon.exe`。

```text
src/WeatherBeacon.App/              WPF 界面、设置及 Windows 集成
src/WeatherBeacon.Core/             天气模型与接口
src/WeatherBeacon.Infrastructure/   天气与城市服务
tests/                             自动检查与界面回归工具
docs/                              设计参考及开发记录
```
