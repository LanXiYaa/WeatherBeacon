# WeatherBeacon 1.0.0.0 — 第二步（x64）

本版在第一步桌面显示与托盘逻辑上实现自由位置、不透明动态天气、动画暂停、设置窗口材质、页面过渡和滑块开关。未推进首次引导、开机自启、预警通知、日志或开发者模式，也没有新增空页面。

发布程序：`release/stage2-win-x64/WeatherBeacon.exe`。版本统一为 `1.0.0.0`，仅生成 x64 自包含版本。

## 完成内容

- 删除四角位置选项。小组件可直接拖动，松手保存显示器、物理矩形、DPI 与工作区归一化位置；启动和显示器变化时恢复并约束到可见工作区。
- 小组件使用不透明天气背景，支持晴昼、晴夜、多云、阴、雨、雪、雾、雷暴；文字区域均有暗色衬底。关闭动画后保留详细静态天气画面。
- 动画约 30 fps；手动隐藏、不可见或被完全遮挡时停止，部分可见时继续。
- 设置窗口独立支持云母、云母 Alt、亚克力和纯色。切换立即生效，DWM 不支持时显示原因并自动降级为纯色。
- 页面切换使用 250 ms 淡入和 8 px 位移，快速连续点击会取消旧动画并落到唯一目标页。
- 所有设置开关均为 Toggle Button，无 CheckBox；包含滑块、颜色渐变、悬停、按下、禁用与键盘焦点状态。
