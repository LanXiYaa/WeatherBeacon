# 毛玻璃启动可见性回归修复 / 1.0.0.0 / x64

## 原因和证据
glass-ui-win-x64/logs/desktop-20261024-001103-2264.jsonl 记录窗口为 460×626，在主屏范围内，可见且未最小化，userHidden=false，父窗口为 WorkerW 0x30BB0。
当前第二步源码重新调用 desktop.Attach(this)，而此前用户确认能显示的回退版使用 StartOrdinary(this)。本次恢复 StartOrdinary，修正重新启用故障嵌入路径的回归。具体 Explorer 合成/遮挡机制未进一步证实；不能单凭 centerBelongsToWidget=false 推断完全被遮挡。

## 修改
- 保留毛玻璃 UI，恢复已验证的普通非置顶窗口启动路径，不调用 WorkerW 嵌入。
- 设置明确提示回退模式。原有嵌入失败解除父子关系并恢复普通窗口的防御代码保留。
- 日志增加实际读取的完整保存位置、显示器、动画初始化/帧数及失败静态降级状态。
- 保存位置不与任何当前工作区相交，或相对坐标非法时，重置到主显示器默认位置。
- 动画绘制抛出异常时停止动画、隐藏动态层、保留静态玻璃背景及文字，并记录降级。

日志：程序目录 logs/desktop-时间-PID.jsonl。startup-final 记录布局；animation-startup-check 是随后真正绘制后的动画状态。
