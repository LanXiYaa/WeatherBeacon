# WeatherBeacon 装饰艺术界面更新

版本：1.0.0.0；架构：x64。由 AI 使用 frontend-design skill 设计与实现。

## 设计
午夜蓝 #142B3B、孔雀青 #237E83、香槟金 #E8C783、冰青 #92DAD5、象牙白 #F5F2E9、珊瑚 #EF927E。
品牌字体 Georgia，正文 Microsoft YaHei UI，温度 Segoe UI。布局保留原来的阅读顺序。

```text
小组件：城市 / 品牌 → 温度 / 天气 → 逐小时 → 逐日 → 更新状态
设置：品牌栏 → 左侧导航 | 页面标题、设置项 → 保存与状态
```

装饰集中于双线边框和设置品牌区的几何放射线。保留系统材质和降级逻辑；不增加背景动画。
统一外观、天气、关于、通知、开发者页面的按钮、选择器、开关、滚动条与强调色。
修复开关选中轨道被灰色层遮盖；提高小组件文字对比度，移除遮盖天气画面的重模糊。
托盘和系统确认框继续遵守 Windows 原生样式，Toast 由系统决定呈现，不强行绘制品牌外壳。
